# Опросник «Что мы говорим детям? Что они слышат?»

Публичная страница опроса для участников (магистерская диссертация А. В. Вологжиной).

- `index.html` — страница опроса. Содержит **только публичный ключ** (для шифрования ответов участников).
- Закрытый ключ расшифровки и админки исследователя здесь **не публикуются** — они передаются отдельно (архивом исследователю).

## Как обновить страницу

Собрать и опубликовать одной командой (из папки `asv` рядом с этим репозиторием):

```bash
cd ../asv && ./publish-site.sh
```

Скрипт пересобирает опросник (`node build_secure.js`), копирует
`otvet/vavmind_test.html` в `index.html`, коммитит и пушит.
После пуша GitHub Pages обновится автоматически.
